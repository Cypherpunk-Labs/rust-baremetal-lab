## Phase 3: The x86_64 Kernel

The x86_64 target requires a custom JSON specification to disable SSE registers, dynamically recompiling the `core` library, and a bootloader to transition from 16-bit to 64-bit long mode.

**1. Initialize the Project**

```bash
cargo new os_x86 --bin
cd os_x86

```

**2. Add Bootloader Dependency (`Cargo.toml`)**

```toml
[dependencies]
bootloader = "0.9"

```

**3. Configure Cargo (`.cargo/config.toml`)**
Create this file to recompile `core` for the custom target and automatically run `bootimage`.

```toml
[build]
target = "x86_64-unknown-none"

# Force the compiler to use a static relocation model
[target.x86_64-unknown-none]
rustflags = ["-C", "relocation-model=static"]

[target.'cfg(target_os = "none")']
runner = "bootimage runner"

```

**4. Write the Kernel (`src/main.rs`)**

```rust
#![no_std]
#![no_main]

use core::panic::PanicInfo;

static HELLO: &[u8] = b"Hello baremetal world from x86_64 on MacOS!";

#[panic_handler]
fn panic(_info: &PanicInfo) -> ! {
    loop {}
}

#[unsafe(no_mangle)]
pub extern "C" fn _start() -> ! {
    let vga_buffer = 0xb8000 as *mut u8;

    for (i, &byte) in HELLO.iter().enumerate() {
        unsafe {
            *vga_buffer.offset(i as isize * 2) = byte;
            *vga_buffer.offset(i as isize * 2 + 1) = 0xb; 
        }
    }

    loop {}
}

```

**5. Build and Boot**

```bash
cargo bootimage
qemu-system-x86_64 -drive format=raw,file=target/x86_64-unknown-none/debug/bootimage-os_x86.bin
```
